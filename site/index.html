THE GAP

文件改了，不等于质量闭环也改了。

一次工艺、材料或检验变更，可能同时影响五类受控文件。人工搜索容易漏项， 通用聊天模型又很难证明结论来自哪个版本、哪一行和哪份证据。

01

跨文档断链

流程、PFMEA、控制计划、SOP、检验记录分散维护，局部修改可能让旧风险复发。

02

证据无法定位

答案没有版本、字段、位置和哈希锚点，无法进入正式评审与追溯。

03

高风险动作越权

缺少精确批准和复跑门禁时，修订不应自动应用，更不能直接建立新基线。

MULTI-AGENT CONTROL LOOP

四个角色，各守一段确定性边界。

Agent 负责拆解、传递与解释；版本、身份、审批和验证结论由可执行契约控制。 当前 Trace 为本地确定性协同契约，AgentTeams 运行时适配处于下一阶段。

01

COORDINATE

质量任务协调 Agent

接收事件、约束任务范围、建立共享状态。
02

PLAN

影响分析 Agent

编译受影响工序、特性、文件和规则计划。
03

VERIFY

证据回归 Agent

运行三态规则，定位每一条证据与冲突。
04

GATE

审批与基线 Agent

校验精确批准；复跑未通过则不建立基线。

STATIC CONTRACT WALKTHROUGH

不是给一个答案，而是留下整条证据链。
